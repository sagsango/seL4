seL4 CAPABILITY TYPES — AArch64 QEMU lab
========================================

Scope
  The primary table comes from the generated cap_tag enum for this lab.
  Current configuration uses EL2, a single core, and classic non-MCS IPC.
  Each bordered row describes one capability tag. Long cells wrap within
  their columns. The checks are a source-reading guide. Several operations
  have additional conditions and architecture-specific errors.

How to read the table
  The CPtr is resolved in the caller's CSpace. A CNode slot is a cte_t
  containing cap_t plus cteMDBNode. cap_t has two 64-bit words in this
  build, with a tag identifying the type-specific fields. Syscall
  dispatch checks that the cap supports the operation, and its decoder
  validates rights, arguments and any additional caps. Shared entry
  points are handleInvocation(), lookupCapAndSlot(), resolveAddressBits(),
  decodeInvocation() and, for most AArch64 memory caps, decodeARMMMUInvocation().

# Example of cap creation:
static inline cap_t CONST
cap_page_table_cap_new(uint64_t capPTMappedASID, uint64_t capPTBasePtr, uint64_t capPTIsMapped, uint64_t capPTMappedAddress) {
    cap_t cap;

    /* fail if user has passed bits that we will override */
    assert((capPTMappedASID & ~0xffffull) == ((0 && (capPTMappedASID & (1ull << 47))) ? 0x0 : 0));
    assert((capPTBasePtr & ~0xffffffffffffull) == ((0 && (capPTBasePtr & (1ull << 47))) ? 0x0 : 0));
    assert(((uint64_t)cap_page_table_cap & ~0x1full) == ((0 && ((uint64_t)cap_page_table_cap & (1ull << 47))) ? 0x0 : 0));
    assert((capPTIsMapped & ~0x1ull) == ((0 && (capPTIsMapped & (1ull << 47))) ? 0x0 : 0));
    assert((capPTMappedAddress & ~0xfffffff00000ull) == ((0 && (capPTMappedAddress & (1ull << 47))) ? 0x0 : 0));

    cap.words[0] = 0
        | ((uint64_t)cap_page_table_cap & 0x1full) << 59
        | (capPTIsMapped & 0x1ull) << 48
        | (capPTMappedAddress & 0xfffffff00000ull) >> 0;
    cap.words[1] = 0
        | (capPTMappedASID & 0xffffull) << 48
        | (capPTBasePtr & 0xffffffffffffull) >> 0;

    return cap;
}
